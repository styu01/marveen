01 Célkitűzés és kontextus

A Béla Home egy személyre szabott konyhai AI asszisztens, amely a Kiss família mindennapi konyhai életét segíti. A rendszer egy lokális WSL2 szerveren fut (Node.js/Express, port 3421), és tablet böngészőn érhető el a home WiFi-n. A chat mögött OpenAI API dolgozik (Whisper STT, gpt-4o-mini, TTS), de az adatok és a konfiguráció a saját gépen maradnak.

A Béla Home nem generikus AI. Tudja ki Istvan, ismeri a Kiss família naptárát és kontextusát, direktbe kapcsolódik a BÉLA rendszerhez. Egyetlen kereskedelmi asszisztens sem tud ilyet reprodukálni — erre kell a fejlesztési fókuszt helyezni, nem a nyers hangfelismerési versenyre az Amazon/Google hardverével szemben.

Istvan visszajelzése szerint az alkalmazás "szétszórt" — ez a dokumentum azt célozza, hogy minden funkció célja, működése, hiányossága és fejlesztési potenciálja átgondolt legyen. Szerzők: BÉLA (technikai elemzés) + OKOSKA (UX és stratégia).

03 Funkciók értékelése

🎤 Hang interface (STT + TTS)
FejlesztendőMindenki
Jelenlegi működés
Push-to-talk: mikrofon gomb → Whisper STT ($0.006/perc) → gpt-4o-mini → OpenAI TTS (onyx, 9 hang választható, localStorage-ban megmarad).
Problémák
  • Konyhai háttérzaj (sütés, vízcsap, elszívó) rontja a Whisper pontosságát
  • Push-to-talk nem hands-free — ha mindkét kéz piszkos, nem tudja leállítani
  • Nincs csend-detektálás (auto-stop)
  • STT timeout kezelés hiányzik → UI befagyhat Whisper késésnél
Javasolt javítás (sprint 2)
Voice Activity Detection (VAD): 1.5 másodperc csend után automatikus stop. Könyvtár: @ricky0123/vad-web (böngésző-oldali, ingyenes). Ezzel a felvétel teljesen hands-free lesz.
Fejlesztési lehetőség
Lokális Whisper.cpp a WSL2-n (offline STT, nulla API cost, nem kell internet). ElevenLabs Turbo v2.5 TTS Istvan saját hangjával.
👂 Ébresztőszó ("Szia Béla")
Fejlesztendő
Jelenlegi működés
Web Speech Recognition API, continuous, hu-HU. Ébresztőszó felismerés után micBtn.click() → felvétel indul. Manuális leállítás szükséges.
Problémák
  • Nem igazán hands-free: ébresztő aktivál, de felvétel leállítása nem automatikus
  • Folyamatos Web Speech API futás battery drain tableten
  • iOS Safarín nem működik (Chrome/Android a target platform)
Javasolt javítás
VAD integrációval az ébresztőszó + auto-stop = teljes hands-free folyamat. Chrome/Android tableten tökéletesen fog működni.
Fejlesztési lehetőség
Picovoice Porcupine: offline wake word, "Hey Béla" egyéni modell edzethető. Nulla API cost, nincs continuous browser API, hosszabb tablet battery.
💬 Chat és AI válasz
Alapok működnekMulti-turn recept hiányzik
Jelenlegi működés
Textarea + Enter, gpt-4o. XSS-védett renderelés (esc() helper). Kettős válasz: rövid (TTS), hosszú (markdown). Chat history localStorage-ban megmarad (bela-chat-history, utolsó üzenetek visszatöltve session között). 20s AbortController timeout + BÉLA-hangú hibaüzenet (timeout / offline / általános hiba) -- ez a v1.0-ban még hiányzott, most kész.
YouTube / link kezelés — MEGCSINÁLVA
Markdown renderer [szöveg](url) felismerést kapott, YouTube linkek "▶ YouTube" feliratú kattintható linkként jelennek meg, más URL is klikkelhető. In-app viewer nyitja meg (nem külső tab), YouTube esetén embed nézetben — ez enyhén eltér az eredeti "csak sima link" kéréstől, érdemes megnézni élőben hogy Istvan szerint ez jó-e vagy tényleg sima linket akar autoplay nélkül.
Multi-turn recept mód (még nincs)
Főzés közben hasznosabb lenne "lépésről lépésre" mód: a felhasználó mondja "kész, mi a következő?" és BÉLA csak az aktuális lépést mondja hangosan. Piszkos kézzel is követhető, nincs hosszú szöveget olvasni. Nincs a kanban-on -- ha kell, ezt fel kell venni külön feladatnak.
🌡 Időjárás widget
Működik
Jelenlegi működés
wttr.in API, 3 napos előrejelzés, 10 percenként frissül. Chat kérdésnél szerver injektálja az aktuális adatot a gpt-4o-mini system promptba.
Problémák
Budapest hardcoded. wttr.in megbízhatatlan, nincs fallback. UV index, pollen count hiányzik.
Fejlesztési lehetőség
Settings panelban beállítható város (nyaraláshoz). Open-Meteo fallback API (ingyenes, megbízhatóbb).
⏱ Időzítők
Kritikus hiba javítvaErika · főzés
Jelenlegi működés
Preset gombok (1/2/3/5/10 perc, összeadódnak), hang aktiválható ("tegyél 10 perces időzítőt"), több timer egyszerre. Lejáratnál zene szól amíg nincs nyugtázva (Oké, vettem gomb) + vibrálás. Bal sáv, saját szekció.
Korábbi kritikus hiba — JAVÍTVA
localStorage perzisztencia kész (bela-timers: endMs + label + preset összeg). Oldal frissítésnél a timer visszaáll, nem vész el.
Maradék hiányosság
Ha a tablet elaludt (screen off / böngésző háttérben), a JS timer nem fut tovább pontosan -- Service Worker + Web Push Notification lenne a megbízható megoldás, ez még nincs meg. Sprint 2-es tétel, ld. roadmap.
🔔 Emlékeztetők
Fejlesztendő
Jelenlegi működés
Szerver oldalon (kitchen-reminders.json), CRUD API, 60 másodperces polling. AI chat-ból hozható létre: "emlékeztess 5-re hogy hívjam fel Erikát".
Problémák
  • Tablet sleep: a polling nem fut → elmulasztja az időpontot
  • Nincs ismétlő emlékeztető ("minden hétfőn reggel: bevásárlólista")
Fix
Service Worker Notification API. recurrence: "daily"|"weekly" mező. BÉLA is tud Telegram-ból emlékeztetőt felveni a konyhai JSON-ba.
🛒 Bevásárlólista
Email + kategorizálás kész, szinkron még nemErika · elsősorban

Fix (Sprint 2, még nyitott)

Fejlesztési lehetőség

🌅 Reggeli briefing
MűködikFallback hiányzik
Jelenlegi működés

📅 Naptár integráció
Visszajelzés készMax 30 perc késleltetés
Jelenlegi működés
Chat: "vedd fel a naptárba csütörtökre 10-re a fogorvost" → kitchen-calendar-requests.json → BÉLA heartbeat (max 30 perc) feldolgozza → Google Naptárba kerül.
Visszajelzés — MEGCSINÁLVA
A rendszerprompt most kötelezővé teszi, hogy a "short" válasz visszaismételje a konkrét, kiszámolt dátumot ("csütörtökön, július 24-én 10 órára felvettem a fogorvost"). A modell a mai valós dátum alapján számol, ISO formátumban tárol. A félreértés így azonnal kiderül, nem kell megvárni a heartbeat-et.
Maradék korlát
A tényleges Google Naptárba írás még mindig a heartbeat-re (max 30 perc) vár -- a visszajelzés csak az értelmezést igazolja, nem a felvétel megtörténtét.
Fejlesztési lehetőség
Google Calendar direct API OAuth token fájlból — azonnali felvétel, nem kell a heartbeat-re várni.
🍳 Recept funkció
Hallucináció kockázat
Jelenlegi működés
Chat kérdés → gpt-4o-mini → recept kártya (hozzávalók + lépések). TheMealDB-ből valódi link injektálva HU→EN fordítási szótárral (csirke→chicken stb.).
Problémák
  • TheMealDB angol — ~20 szós szótár, sok magyar étel hiányzik
  • Ha TheMealDB nem ismeri: a modell hajlamos kitalálni a linket
  • Nincs "hűtő-alapú" recept: "tojás + sajt + paprika → mit csináljak?"
Fejlesztési lehetőség
Magyar receptadatbázis (Nosalty.hu scraper/RSS). Hűtő-inventory mező a profilban → vacsorajavaslat amit valóban meg lehet csinálni. Hozzávalók → bevásárlólistára automatikus gomb.

04 Memória és perzisztencia

Istvan kérése: "legyen memóriája." Ez az, ami a Béla Home-ot ténylegesen megkülönbözteti egy Alexa-tól: a Kiss-specifikus hosszú távú kontextus. Nem kell komplex motor — egy jól felépített JSON fájl elég kezdetnek.
Személyes profil — kitchen-profiles.json
Kész
Mit tartalmaz
4 profil: Istvan (kedvenc ételek: gulyás, rántott hús, pörkölt; fűszeres ételek szeretete), Erika (laktózmentes diéta), Ádám (mogyoró allergia), Viktória (kedvenc étel: palacsinta). Mezők: kedvenc_etelek, kedvenc_alapanyagok, allergenek, dieta, megjegyzes.
Megvalósítás — LESZÁLLÍTVA
store/kitchen-profiles.json, szerver oldali CRUD API (GET/POST /api/profile/:person). Kliens oldalon személyválasztó gomb (currentPerson), minden /api/chat hívás a kiválasztott személy profilját injektálja a system promptba.
Nyitva maradt
Nincs saját szerkesztő UI a profilokhoz a Settings panelban -- jelenleg csak API-n vagy a JSON fájl közvetlen szerkesztésével módosítható. Ha kell felhasználói felület hozzá, ez egy külön, kicsi feladat.
Tanult emlékek — kitchen-memory.json
Sprint 2
Mit tartalmaz
Amit a chat során mond a felhasználó és nem volt a profilban: "Sok fokhagymával szeretem a csirkét", "csütörtökönként Erika edzésre jár", "Ádám mostanában sok szendvicset eszik".
Megvalósítás
Kulcs-érték JSON. Ha a modell "megjegyeznivalót" azonosít a válaszban, szerver felírja. System promptba bekerül "Megjegyzett dolgok:" szekcióként. Max 20 tétel, FIFO rotáció.

Hibaüzenetek — BÉLA-hangnem — KÉSZ

A rendszerprompt kötelezővé teszi, hogy a chat "short" válasz visszaismételje az értelmezett konkrét dátumot, a valós mai nap alapján kiszámolva. Ez azonnal detektálhatóvá teszi a félreértéseket, nem kell a heartbeat-re várni az ellenőrzéshez.
